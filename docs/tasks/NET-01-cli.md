# NET-01 — Каркас проекта и CLI

Создать минимальную основу, которая принимает URL и позволяет тестировать модуль
без сетевых побочных эффектов при импорте.

## Объём

- Выбрать отдельный Python 3.12+, создать `.venv` для инструментов разработки.
- Создать `speedtest.py` с `main() -> int`, `argparse` и проверкой URL по контракту.
- Создать `pyproject.toml` с настройками из AGENTS.md и `requirements-dev.txt`
  с точной проверенной версией Ruff. Приложение не требует сторонних библиотек.
- Создать `.gitignore` для виртуального окружения, кэшей Python/Ruff и секретов.
- Добавить начальные проверки CLI в `tests/test_speedtest.py`.

## Критерии приёмки

- [x] `--help` описывает URL и завершается с кодом `0` без обращения к сети.
- [x] Нет URL, неподдерживаемая схема, пустой хост или неверный порт дают код `2`
  и сообщение в stderr до сетевого обращения.
- [x] Корректный HTTP/HTTPS-адрес с query string сохраняется для загрузки.
- [x] Импорт `speedtest` не выполняет запросы и не разбирает аргументы процесса.
- [x] `parse_args` отвечает за аргументы и проверку URL, `main` — за выполнение
  сценария и завершение процесса; границы соответствуют разделу архитектуры AGENTS.md.
- [x] Настроенные проверки Ruff и тесты созданного поведения проходят.

Обработка успешного URL до появления загрузчика — промежуточное состояние;
она не считается готовым приложением и не должна выдавать выдуманные метрики.
