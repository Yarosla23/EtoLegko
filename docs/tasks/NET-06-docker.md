# NET-06 — Запуск через Docker на Linux

Добавить запрошенный пользователем запуск через Docker. Область изменений:
`Dockerfile`, `.dockerignore`, README, AGENTS.md, контракт и индекс тикетов.
Поведение и архитектура Python-скрипта сохраняются.

## Критерии приёмки

- [x] Образ на официальном Python собирается командой из README.
  В образ попадают только файл запуска и программные модули; процесс работает без root.
- [x] URL и `--help` передаются скрипту через exec-форму ENTRYPOINT;
  ошибки аргументов сохраняют код 2 и сообщение в stderr.
- [x] Из контейнера выполнены 26 тестов и замер на локальном HTTP-ресурсе;
  проверены десять полных загрузок и общий объём.
- [x] README описывает основной запуск через Docker на Linux, пересборку,
  тесты и доступ к локальному серверу хоста. Windows-команды удалены.
- [x] Docker-изменения опубликованы в существующем GitHub-репозитории;
  сборка и запуск проверены из полученного с GitHub исходного кода.

## Проверка

Проверка выполнена на Linux amd64, Docker Engine 29.5.3,
Python в образе — 3.15.2.

- `docker build --pull -t etolegko .` — успешно. Контекст со скриптом — 4.84 kB.
  Базовый образ: `python:3.15.2-slim`, digest
  `sha256:65a65fc7b30b06cb6df4930fd4650697cb23f4c2698ab81fc87e4b031bc36928`.
- Проверка исходной версии образа через `--entrypoint python`: UID 10001,
  в `/app` только `speedtest.py`. Добавление пакета перепроверено в NET-07.
- `docker run --rm etolegko --help` — код 0; URL `file:///etc/passwd` — код 2,
  ошибка аргументов без обращения к файлу.
- Команда тестов из README с read-only подключением `tests` — 26 тестов прошли.
- Локальный прогон двух контейнеров по README с `--network host`: сервер получил
  ровно 10 GET-запросов, скачано 89 180 байт (десять размеров README), 1.918 MiB/s.
  Проверочный сервер удалён после прогона.
- Внешний запуск Docker по README: логотип python.org, 10 запросов,
  157 700 байт, среднее 0.384 s, 0.039 MiB/s, код 0.
- Обе проверки Ruff — успешно. Код Python не изменялся.
