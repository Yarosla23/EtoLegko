# NET-04 — Проверка полного сценария

Проверить работу готового скрипта целиком. Дополнить существующий
`tests/test_speedtest.py`, исправляя найденные дефекты в `speedtest.py`.

## Критерии приёмки

- [x] Интеграционный тест поднимает локальный HTTP-сервер на свободном порту,
  запускает CLI отдельным процессом и проверяет успешный код, итоговый объём
  и ровно 10 завершённых обращений. Сервер и процесс освобождаются после теста.
- [x] Тело тестового ответа больше одной порции чтения; сервер отдаёт его частями.
  Тесты порядка чтения из NET-02 остаются частью проверки последовательности.
- [x] Покрыты ответ без `Content-Length`, редирект, 404, таймаут и обрыв тела;
  для редиректа проверяется 10 логических загрузок с дополнительными обменами.
  Ожидания и ошибки можно подменять, чтобы тесты оставались быстрыми.
- [x] На ошибочных сценариях проверены код завершения, stderr и отсутствие
  успешного отчёта. Покрытие из NET-01–03 используется повторно.
- [x] Автотесты не обращаются во внешний интернет, не полагаются на `sleep`
  и пороги скорости; процессы тестов имеют ограничение времени выполнения.
- [x] `unittest`, обе проверки Ruff и `--help` проходят на Python 3.12
  и рекомендованной рабочей версии. Фактически использованные версии записаны.

## Проверка

Выполнено 18.11.2026 на Linux. Одинаковые проверки прошли на CPython 3.12.16
(`.venv-312/bin/python`) и CPython 3.15.2 (`.venv/bin/python`):

- `<python> -m unittest discover -s tests -v` — 26 тестов, успешно.
- `<python> -m ruff check .` — успешно, Ruff 0.17.5.
- `<python> -m ruff format --check .` — успешно.
- `<python> speedtest.py --help` — код 0.

Интеграционные тесты проверили тело 76 800 байт, отданное частями, отсутствие
Content-Length, chunked, 302, 404, преждевременный EOF и пустой 204.
Каждый дочерний процесс ограничен 15 секундами; таймаут/порядок/время проверяются
управляемыми подменами без sleep. Сервер закрывается через cleanup unittest.
Из-за запрета сокетов в обычной песочнице полные тесты запущены с разрешением
на локальный HTTP-сервер; внешний интернет в тестах не использовался.
