# NET-05 — README и GitHub

Подготовить результат к проверке другим разработчиком и опубликовать решение.
Изменения: корневой `README.md`, при необходимости `.gitignore`; затем Git/GitHub.

## Критерии приёмки

- [x] README описывает назначение, Python 3.12+, рекомендуемую версию и запуск
  с URL без установки сторонних библиотек. Есть команды для Linux/macOS
  и Windows, с URL в кавычках.
- [x] Есть пример вывода, формулы, определение MiB/s и подсчёта байтов тела.
  Описаны десять последовательных загрузок, редиректы, таймаут и остановка
  при ошибке; ограничения оценки скорости изложены кратко.
- [x] Есть команды тестов, создания `.venv` и установки Ruff из
  `requirements-dev.txt`; RTK не требуется пользователю скрипта.
- [x] Пример из README выполнен на локальном ресурсе; один реальный сетевой
  замер выполнен отдельно. Его URL, дата и результат записаны в проверке,
  без вывода секретов. Синтетические числа помечены как пример.
- [x] В целевом GitHub-репозитории опубликованы код, тесты и документация;
  окружение, секреты и скачанные файлы исключены. Приложена доступная ссылка.
- [x] Из свежего клона по README успешно выполнены запуск на локальном ресурсе
  и тесты. Подтверждено отсутствие зависимости от локальных путей автора.

Если место публикации неизвестно, выяснить его на этапе готового локального
решения. При отсутствии доступа отметить причину и сохранить готовые файлы;
весь тикет остаётся незавершённым до публикации и проверки свежего клона.
