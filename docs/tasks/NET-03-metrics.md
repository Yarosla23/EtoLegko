# NET-03 — Метрики и вывод

Связать результаты загрузок с формулами и форматом вывода из контракта.
Изменения: `speedtest.py` и тесты расчёта в `tests/test_speedtest.py`.

## Критерии приёмки

- [x] `calculate_statistics` вычисляет метрики без побочных эффектов;
  форматирование, округление и печать выполняются на границе CLI.
- [x] Среднее время, общий объём и скорость считаются по разделу «Расчёты»;
  округление выполняется только при печати.
- [x] После 10 успешных загрузок stdout содержит все четыре поля из контракта,
  процесс завершается с кодом `0`.
- [x] Контрольный пример: 10 ответов по `1_048_576` байт за `0.5` секунды каждый
  дают `0.500 s`, `10485760 bytes` и `2.000 MiB/s`.
- [x] Тест с разными длительностями и объёмами отличает общую скорость
  от арифметического среднего отдельных скоростей.
- [x] Пустые ответы при положительном времени дают `0.000 MiB/s`;
  неположительное суммарное время даёт управляемую ошибку с кодом `1`.
- [x] Тесты проверяют математику и вывод с подменой времени;
  Ruff и накопленные тесты проходят.

## Проверка

Выполнено 18.11.2026 на CPython 3.15.2.

- `.venv/bin/python -m unittest discover -s tests -v` — 20 тестов прошли.
  Проверены эталонный отчёт, разные объёмы/длительности, пустые тела,
  неположительное время и неполный набор измерений.
- `.venv/bin/python -m ruff check .` и `format --check .` — успешно.
