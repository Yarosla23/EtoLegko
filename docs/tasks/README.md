и получения доступа к GitHub. Тесты на отдельное поведение входят в NET-01–03;
NET-04 проверяет их совместную работу. Двухдневный срок оставляет время
на установку окружения и публикацию.

В первый день выполнить NET-01–03, во второй — NET-04–05.

## Правила выполнения

- Переходы статусов: `todo` → `in_progress` → `done`.
  Если нужен внешний доступ, используй `blocked` с конкретной причиной.
- Зависимость считается выполненной только при её статусе `done`.
- Для завершения нужны все критерии приёмки и фактические результаты проверок.
  Наличие кода само по себе не закрывает тикет.
- Для NET-05 нужны работающий GitHub-доступ и известное место публикации.
  При их отсутствии можно подготовить локальное решение, но публикация остаётся
  незавершённой. Подготовка тикетов сама по себе ничего не публикует.

## Окружение на момент подготовки

18.11.2026 команда `python3` в этой среде показывает `3.10.12`.
При NET-01 нужно выбрать или установить отдельный Python 3.12+;
системный интерпретатор не заменять. При реализации отдельно установлены CPython
3.12.16 и 3.15.2 в `/tmp`; `.venv` использует 3.15.2, `.venv-312` — 3.12.16.
Системный Python сохранён. Ruff 0.17.5 установлен только в этих окружениях.
